## Non-obvious drift

### 1. Раздельное research vs. implementation: почему не PR на main

Cart #52 только в первой research-волне. Принятие Fly.io (= ADR-0004) — это **precondition**, не deliverable. Implementation тикеты (#54 `fly.toml`, #55 secrets docs, #56 DNS, #57 smoke) придут следующими волнами и будут shipped через отдельные PR'ы, которые:

- подтянут `research/52-hosting` через merge или cherry-pick (чтобы ADR-0004 оказался на `main`),
- либо (как было в cart-42) ссылаются на ADR-0004 прямо из коммит-сообщений и несут ADR-файл в своём PR.

Per AGENTS.md rule #9 — `openapi.yaml`/SDK/CHANGELOG.md/version сгенерированные, ручная правка запрещена. **`docs/adr/0004-*.md` НЕ входит в этот список** (документ решения, не продукт pipeline). Можно править руками до тех пор, пока решение не «схвачено» конкретным PR.

### 2. `#verify-pricing` drift-marker (matrix в ADR содержит конкретные \$/месяц значения)

Fly.io pricing page — данные на 2026-11-04 (`shared-cpu-1x` 256MB = $2.19/месяц, 512MB = $3.69, autostop idle = ~$0.45/месяц при 2ч/день активной работы). Через квартал эти числа могут сдвинуться (особенно после ребрендов managed services, как было у Fly в 2024). Структурное решение Fly vs Render/Railway от price drift **не** зависит — там сравнение по capability-факторам (Docker, TLS, secrets-via-dashboard, scale-to-zero elegance). Конкретный shape (`shared-cpu-1x` 256MB, `min_machines_running=0/1`) может быть скорректирован в landing-коммите #54 без новой research-волны.

Эта drift-маркер проставлен в text ADR'а как «#verify-pricing», продублирован в cart #52 body и в closing-комментарии #53. Execution следующей сессии должна найти его grep'ом.

### 3. Vercel отвергнут структурно (не по цене, а по shape mismatch)

Vercel Container существует, но **не first-class для long-running stateful backend**. Их pricing, docs и deployment model построены вокруг serverless Functions (Active CPU, Provisioned Memory, Invocations). `booking-api` с in-memory `BookingStore` не подходит под эту модель:

- horizontal autoscale (запрещён ADR-0001/0002 — single-writer in-memory store);
- cold-starts Functions — это другой skyline латентности;
- persistent state между запросами требует **именно** long-running container instance.

Reject без отдельной `Wayfinder:research` ветки — структурное решение видно сразу.

### 4. Render и Railway pricing не загружались (webfetch timeout)

При попытке webfetch `https://render.com/pricing`, `https://docs.railway.com/...`, `https://railway.com/pricing` — все три раза timeout. Можно было сделать retry, но для **структурного решения** численные pricing-таблицы не нужны. Сравнительная матрица построена по capability-факторам (AC #53), а конкретные \$ приняты только для Fly.io с явным `#verify-pricing` drift-marker'ом.

Если в будущей сессии потребуется re-evaluate Fly vs Render/Railway (например, после того как Fly поднимет цены в 2x), нужно открыть новый research-ticket и переписать ADR-0004 заново.
