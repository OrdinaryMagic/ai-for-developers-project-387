# Лейблы триажа

Скиллы оперируют пятью каноническими ролями. Этот файл сопоставляет каждую роль реальной строке лейбла, используемой в трекере задач этого репозитория.

| Роль в mattpocock/skills | Лейбл в нашем трекере | Смысл                                    |
| ------------------------ | --------------------- | ---------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнер должен разобрать эту задачу   |
| `needs-info`             | `needs-info`          | Ждём от автора дополнительной информации |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описана, готова для AFK-агента |
| `ready-for-human`        | `ready-for-human`     | Требует ручной реализации человеком      |
| `wontfix`                | `wontfix`             | Не будет реализовано                     |

Когда скилл упоминает роль (например «применить лейбл готовности к AFK»), используй соответствующую строку лейбла из этой таблицы.

Отредактируй колонку «Лейбл в нашем трекере», если у тебя другая лексика.
